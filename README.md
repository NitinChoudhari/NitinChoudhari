### About me

I'm a Software Engineer at **LTIMindtree (Pune)** with 3+ years of experience, currently shipping production GenAI systems.

- 🚀 I designed and deployed a **multi-agent LLM system** (crewAI + LangChain + ChromaDB) at a Fortune 500 client — running across DEV, IMP, and PROD environments, used daily by developers, BAs, QA, and scrum masters to automate root-cause analysis on ServiceNow incidents.

- 🧠 Currently going deep on **ML/DL fundamentals** — implementing classical ML algorithms from scratch in NumPy, working through Karpathy's *Neural Networks: Zero to Hero*, and building toward research-engineer-level depth.

- 🎓 Completing my **Executive MBA** at Symbiosis (SIMS), expected June 2026.

- 🛠️ Building **[LogMind](https://github.com/nitinchoudhari/LogMind)** — a personal multi-agent RAG system for log analysis (RAG + crewAI + Tavily + local LLMs via Ollama).

- 📚 Learning publicly in **[ml-deep-dive](https://github.com/nitinchoudhari/ml-deep-dive)** — from-scratch implementations of ML algorithms in pure NumPy.
