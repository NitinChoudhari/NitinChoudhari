### About me

I'm a Senior Software Engineer at **LTIMindtree (Pune)** with 4+ years of experience, shipping production GenAI and agentic AI systems in a regulated (insurance / financial services) domain.

- I designed and deployed a **production multi-agent LLM system** (crewAI + LangChain) at a Fortune 500 client — running across DEV, IMP, and PROD environments, used daily by 16 engineers across Dev, QA, and BA teams to automate root-cause analysis on ServiceNow incidents. Hybrid retrieval (BM25 + semantic), query decomposition, cross-encoder reranking, and typed Pydantic outputs.

- Building **[LogMind](https://github.com/nitinchoudhari/LogMind)** — a local-first multi-agent RAG knowledge platform: crewAI orchestration, hybrid dense + sparse retrieval on Qdrant, BGE cross-encoder reranking, real-time web search via Tavily, and **LLMs fine-tuned with PEFT (QLoRA)** — all running on consumer GPU hardware with KV caching and FlashAttention-enabled runtimes.

- Going deep on **ML/DL fundamentals** in **[ml-deep-dive](https://github.com/nitinchoudhari/ml-deep-dive)** — classical ML algorithms from scratch in NumPy, plus a CNN image classifier built from first principles in PyTorch (forward prop, backprop, gradient descent, architecture design). Curriculum: StatQuest + Karpathy's *Neural Networks: Zero to Hero*.

- **Executive MBA, Finance** — Symbiosis (SIMS), Pune, completed 2026.

- Currently pursuing: **AWS Certified AI Practitioner (AIF-C01)** · **IBM AI Engineering Professional Certificate**
